# 塔系统重构：工厂模式与策略模式

## 概述

我们已经对塔防游戏中的塔系统进行了重构，应用了工厂方法模式来封装塔的创建逻辑，并引入策略模式来管理塔的攻击行为。

## 工厂模式实现

### 文件结构

- `TowerFactory.h` - 定义了抽象工厂接口和具体工厂类
- `TowerFactory.cpp` - 实现了工厂类
- `TowerFactoryExample.h` - 使用示例
- `Tower.cpp` - 修改了原有的createTower函数，现在使用工厂模式

### 设计说明

1. **抽象工厂接口** (`TowerFactory`)
   - 定义了创建塔的统一接口

2. **具体工厂类**
   - `BottleFactory` - 创建瓶子塔
   - `SunFactory` - 创建太阳塔
   - `PlaneFactory` - 创建飞机塔
   - `ShitFactory` - 创建便便塔

3. **工厂提供者** (`TowerFactoryProvider`)
   - 管理所有工厂实例
   - 提供统一的访问接口

### 使用方式

```cpp
// 方式1：使用工厂提供者直接创建塔
Tower* tower = TowerFactoryProvider::createTower(0, 1); // 创建1级瓶子塔

// 方式2：获取具体工厂，然后创建塔
TowerFactory* factory = TowerFactoryProvider::getFactory(0);
Tower* tower = factory->createTower(1); // 创建1级瓶子塔
```

## 策略模式实现

### 文件结构

- `AttackStrategy.h` - 定义了攻击策略接口和具体策略类
- `AttackStrategy.cpp` - 实现了各种攻击策略

### 设计说明

1. **策略接口** (`AttackStrategy`)
   - 定义了攻击行为的统一接口
   - 包含纯虚函数 `attack()` 用于实现具体攻击逻辑

2. **具体策略类**
   - `BottleAttackStrategy` - 瓶子塔攻击策略：单体高伤害
   - `SunAttackStrategy` - 太阳塔攻击策略：范围伤害
   - `PlaneAttackStrategy` - 飞机塔攻击策略：穿透伤害
   - `ShitAttackStrategy` - 粪便塔攻击策略：单体伤害+减速效果

3. **策略集成**
   - 在工厂创建塔时，为每种塔设置对应的攻击策略
   - 塔类通过策略对象执行攻击行为，而不是直接实现攻击逻辑

### 策略模式优势

1. **算法封装** - 每种攻击行为被封装在独立的策略类中
2. **运行时切换** - 可以在运行时改变塔的攻击策略
3. **易于扩展** - 添加新攻击方式只需添加新策略类
4. **符合开闭原则** - 对扩展开放，对修改关闭

## 重构收益

1. **解耦创建逻辑** - 将塔的创建逻辑从使用代码中分离出来
2. **解耦攻击行为** - 将攻击行为从塔类中分离出来
3. **易于扩展** - 添加新塔类型或攻击方式时，只需添加对应的工厂或策略类
4. **符合开闭原则** - 对扩展开放，对修改关闭
5. **统一接口** - 所有塔的创建和攻击都通过统一接口进行
6. **代码复用** - 攻击逻辑可以被不同类型的塔共享

## 后续计划

接下来，我们可以逐步应用其他设计模式：

1. **组件模式** - 将塔的功能拆分为独立组件
2. **装饰器模式** - 重构塔的升级系统
3. **建造者模式** - 重构塔的属性管理
4. **观察者模式** - 重构塔与游戏状态的交互

每一步都会保持代码的简洁性和可维护性，确保系统逐步优化而不是一次性变得复杂。
